# Research Kit

Find a strong starting point for your next lesson. Review original sources, then add your own teaching ideas.

## Connect your source

Enable Web Search in Workshop Connectors if your administrator offers it. Then ask the Workshop agent: “Bind my Web Search connection to this gadget as WEB_SEARCH.” Refresh after the binding is attached. Web Search is not automatically injected into gadget code, and the blueprint connection picker does not configure singleton bindings. No Context collection is read in this version. Do not put student information in a search query.

## Use and share

Refresh loads source records without caching them in gadget storage. Try fictional example reads no account and saves no sample data. Add your own preparation notes and tasks, then choose Save preparation. Concurrent editors use last-save-wins semantics. Source links open the original provider and retain its access checks.

Publish this blueprint to share reusable code; every recipient needs their own authorized connection. Stored notes are workspace data and do not travel with a published blueprint. Do not embed private records in code or public screenshots. No external writes, emails, schedules or model calls are made.

Print the board from your browser, or export Preparation (Markdown) from Workshop. Markdown includes only saved teacher notes and tasks, not provider records.
