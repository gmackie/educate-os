# Home learning family pilot: plan and record

A small pilot of [home learning](../home-learning.md) with real families in one community
installation, to find out whether parents can run it and whether children can use it. This page
is both the plan and the place results are recorded. It holds no family's personal details: use
pseudonyms (Family A, Child A1) and keep consent forms elsewhere.

## Before it starts

- [ ] The packs used have had qualified educator review, recorded in each pack's `review` field, or
      families are told plainly that the content is a draft.
- [ ] Retention for practice evidence is decided and written here.
- [ ] Each family has given written consent, and knows how to export and delete their data.
- [ ] The community installation runs the release under test, with `homeLearning` set.

## What we're checking

| Question | How we'll know | Result |
|---|---|---|
| Can a parent set up a family and a child without help? | Setup completed unaided; time taken; where they got stuck. | |
| Can a parent pick the right activity? | They can say why they chose it; the start point matched the child. | |
| Can a child start and finish an activity alone? | Sessions finished; "Ask my grown-up" use; observed frustration. | |
| Does the lock hold on a shared device? | No child reached a grown-up page; PIN forgotten or locked, and recovered. | |
| Can a parent explain the next step from Progress? | Their explanation matches the evidence shown. | |
| Do interruptions lose work? | Sessions resumed after closing the app or losing the connection. | |
| Does a family without a microphone, or with one child sharing a sibling's device, manage? | Observed. | |

Engagement alone (sessions, minutes) is not a learning outcome. If performance on fresh check
items is reported, report it as what it is: a small, uncontrolled sample.
