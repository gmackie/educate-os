Getting data into the Simulator

Recommended
Local dev district
A dev server built on @educateos/harness: seeded districts, deviceTokenSecret set, a manifest served, and a persona picker on /connect-phone. Dev builds accept http://localhost as a school address, which the Simulator can reach. No real accounts, nothing deployed.
Deployed demo district
Real HTTPS, but only the operator's admin account exists, so there's no student or family data. It would need seeding and Google sign-ins.
Demo mode inside the app
Run @educateos/demo inside the app. It's browser-only today and would skip the real pairing and device-proof path.
