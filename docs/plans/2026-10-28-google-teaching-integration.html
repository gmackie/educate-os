In progress · expanded acceptance

2026-10-28 · EducateOS · SCHO-255 · static API baseline 86c947c

Deliver reusable instructor workflows and student-shareable lessons across all 13 Google connector resources. The source declares 156 methods across 28 interfaces, including cursors and hooks. This is an API inventory, not a count of verified operations.

Student sharing is a delivery gate.

The current Classroom binding permits co-teachers, not students: it exposes roster and grade data. Build a distinct student course/own-work capability and a lesson-materials capability, or publish an explicit reviewed lesson snapshot without the teacher binding. A rendering filter alone cannot protect a shared teacher capability.

Acceptance for each shareable blueprint

Instructor creates from blueprint, grants only required resources and prepares the lesson. An enrolled learner opens it using their own account; a second learner sees only their own work. A co-teacher, non-member and removed learner exercise the appropriate access paths. Repeat after reload, source update, reconnect and provider failure. Verify any Google document/file sharing independently of EducateOS workspace sharing. Record actual identities, blueprint/gadget versions, deployed revision, decision, provider readback and timestamp.
