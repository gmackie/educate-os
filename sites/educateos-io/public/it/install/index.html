For district IT · Install

Install EducateOS in your district's Cloudflare account.

One command, run by your administrator, under a token you create and then delete. This page lists what you need first, the decisions to make, each step and how long it took in our recorded runs, how to check the result and how to remove it.

Install it with usBack to the IT packetRunbook on GitHub
Where the evidence stands. The installer has completed full installs into Cloudflare accounts the project owner runs (2026-10-26 and 2026-11-04), and on 2026-11-18 a timed install into a clean, empty account: about two minutes to install, with the district LMS, and 23 seconds to uninstall, leaving the account empty. No district has run it yet. The times on this page say which run they come from. Steps that depend on you, such as moving a domain or adding your identity provider, are estimates.

The API token

Thirteen permissions, one account, one zone.

The installer prints a link to Cloudflare's token editor with these already filled in. Give the token a short expiry and delete it when the install finishes. EducateOS keeps running without it.

Decisions

Four choices to make first

Your own domain

EducateOS is served on a hostname in a domain your district holds, such as educateos.northfield.k12.example. An <name>.educateos.io address for an install in your own account has been proven by hand on a second account, but isn't in the installer yet. You can add one later.

educateos.io address: In development

Who signs in, and how

The email domains and individual addresses that may sign in, and the identity provider they use: Google Workspace, Microsoft Entra ID, Clever or any SAML or OIDC provider Cloudflare Access supports. Add it to Zero Trust before the install.

Administrators

One to twenty email addresses. They are stored only in your account.

The district LMS and its MCP service

The school release installs the district LMS at / and the AI Workshop at /ai, with the district's MCP service. Each takes a small configuration file. The LMS names administrators by their sign-in identity, so start with a placeholder, sign in once, then run the installer again with the real one. Installing both from an answers file was verified on 2026-11-18; the step-by-step wizard doesn't ask for the MCP configuration yet, so we'll prepare the answers file with you.

Steps

Under an hour, once the prerequisites are in place.

The installer's own time is about two minutes. Most of the hour is reading the plan and checking the result. Moving a domain to Cloudflare or setting up your identity provider, if they aren't done yet, set the real schedule.

StepWhat happensTime
1. Checknpx launch-educate-os doctorChecks Node, downloads the newest release and verifies its signature against keys built into the installer, and checks the token can see the account. About 8 seconds of tool time (clean account, 2026-11-18).2 min
2. Plannpx launch-educate-os planAsks its questions, checks the account (plan, R2, DNS, Zero Trust, permissions) and lists every resource it would create and what Cloudflare bills for. Changes nothing. About 8 seconds (clean account, 2026-11-18). That plan listed 18 changes: 7 Workers, 3 KV namespaces, an R2 bucket, two Access applications and their policies, a generated secret, scheduled jobs and a custom domain.10 min
3. Fixif the check blocksEach blocking item says what to do. Run the plan again; it reuses your answers.0 to a day
4. Installnpx launch-educate-osShows the plan again, asks you to confirm, then creates everything with live progress. About 125 seconds of tool time for those 18 changes (clean account, 2026-11-18). A run that stops partway continues from where it stopped when you run the command again.5 min
5. VerifyRun the plan once more: it should show nothing to change, as it did on 2026-11-18. Open your hostname in a private window: you should be sent to your district sign-in, then EducateOS. Someone outside the admitted domains should be refused.10 min
6. Connectnpx launch-educate-os connectThe installer offers it at the end: your LMS and your roster, one at a time, each ending with a live check. See below. Not yet timed against a real LMS.15 to 30 min each

$npx launch-educate-os plan

Your answers, never the token, are saved to educateos-install.json. Keep it: npx launch-educate-os upgrade and rollback reuse it, and --config educateos-install.json --yes --json runs the same install from CI. The package README lists every command and option.

After install

Connect your LMS and roster.

The installer ends by asking Connect your LMS and roster now? You can also run it any time from the same folder. For each system it says what it gives the district and what you need first, shows the exact steps and values for the other system, stores what the district reads in your own account, and ends with a live check and the next steps for teachers.

The Canvas and Moodle registrations themselves passed live runs by hand on 2026-10-26.

Upgrade, roll back, uninstall

You can leave the way you came in.

  • upgrade installs the newest signed release. The installer refuses an older release than the one you run unless you ask for a rollback.
  • rollback returns every Worker to the previous release, and first lists what it can't undo, such as database migrations already applied.
  • To uninstall, run npx launch-educate-os uninstall: it shows exactly what it would delete, only what the installer made for your install, and deletes it once you type your install's ID. It never empties a storage bucket that still holds files; you do that first. This deletes the district's data too, so export first. On 2026-11-18 it removed a live install from a clean account in 23 seconds and left nothing of it behind.
