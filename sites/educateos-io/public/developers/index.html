For developers

Open source, Workers-native, built to extend.

EducateOS is Cloudflare OS with a district app on top, all Apache-2.0. Every workspace is a Durable Object, every gadget runs in a sandboxed Worker, and every outside service sits behind a gatekeeper you can write yourself.

The building blocks

Gadgets, gatekeepers and bindings.

  • Gadgets are small apps in Dynamic Worker facets, each backed by a Durable Object. The client talks to its server only over Cap'n Web RPC.
  • The agent is a Code Mode agent: it does its work by writing and running code against the bindings it was given.
  • Gatekeepers are Workers that broker each outside service. Reads are recorded, and writes are simulated, then queued for a person.
  • Bindings a gadget can get include a language model, web search, scheduled hooks, Google Workspace and Classroom, any MCP server, and the district's school tools.

Gadgets and blueprints

Build apps by asking, then publish them as blueprints that others copy and connect to their own resources. Bundled blueprints and .gadget export are included.

Write a gatekeeper

The gatekeeper kit handles connect flows, credentials, configurators and the approval queue. Each gatekeeper deploys as its own Worker.

Available in Cloudflare OS

MCP servers and the portal

Any MCP server becomes a typed binding, with one method per tool. The portal connector fronts the servers an admin approved.

Available in Cloudflare OS

School tools (SCHOOL binding)

listTools() and callTool() over the district's directory operations, such as rosters, offerings and enrollments, acting as the verified person.

Run it locally

Two synthetic districts in one command.

# the Workshop: agents, gadgets and gatekeepers
pnpm install
pnpm run-local

# EducateOS: two isolated synthetic districts, each with a fake
# sign-in provider, roster and AI provider
pnpm educateos:harness
pnpm educateos:harness -- --check   # boot, check health, exit

The code is public under Apache-2.0: fork it, run it and build on it. We aren't taking outside pull requests yet. If you want to help, email us.
