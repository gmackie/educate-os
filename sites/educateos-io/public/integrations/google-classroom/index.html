Integrations · Google Classroom

Google Classroom, with grades that wait for the teacher.

Today a teacher connects their own Google account through the Google connector. Their agent can then read the courses they teach, draft coursework, and return grades once the teacher approves each one. District-wide sync is designed but not built.

What happens when something goes wrong

  • If Classroom API access is off for the school, or the project lacks permission, the teacher is told which one.
  • Google's rate limits are retried rather than surfaced as failures.
  • Coursework another app or the teacher created by hand is never listed or changed.
  • Nothing is written to Classroom until the teacher approves it in the queue. A rejected action is never sent.
How we validate. Every status on this page comes from the project's maturity record. Unit-tested features run against fakes that behave like the real service: Classroom API fakes. A feature moves to "Validating against live sandbox" when a run against the vendor's own sandbox is under way, and to "Supported" only after it passes there. More on our testing →
